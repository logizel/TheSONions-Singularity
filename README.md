# TheSONions-Singularity

Problem Statement: Medical Supply Chain

**The STAR method:**
```
Situation (The Problem)

• What’s happening: A hospital across town completely runs out of a life-saving medicine during a sudden disease outbreak.
• The twist: At the exact same time, a different hospital has thousands of units of that exact same medicine sitting on a shelf, but it’s going to expire and be thrown away because the two hospitals don't talk to each other.

Task (Your Goal)

• What you need to build: A smart web app dashboard that acts like an early-warning system.
• The big questions it must answer:
	• What medicine is running low?
	• Where is the shortage happening?
	• When exactly will the shelf be empty?
	• How do we share the stock fairly?

Action (How Your AI Solves It)

Your app clicks into action using three simple steps:
1. The Predictor: It reads hospital data and prints a countdown (e.g., "Hospital A will run out of Medicine X in 6 days").
2. The Waste Catcher: It checks expiration dates and flags unused medicine before it spoils.
3. The Rerouter: It calculates the best way to move the surplus medicine to the hospital facing the shortage, factoring in travel time and patient needs.

Result (What You Actually Show the Judges)

When you present, you will show them a live web dashboard that delivers exactly what they asked for:
• The Visual Cockpit: A single screen showing live charts of inventory and shortage risks.
• The Clear Directives: A simple text box telling the user exactly what to do (e.g., "Move 1,000 units from Hospital B to Hospital A right now").
• The Plain-Language Summary: A clear explanation written in everyday words so a busy hospital manager can understand it in two seconds.
• The Bonus Chat Box: A small AI assistant window where the judges can type questions like, "Who is running out of stock next week?" and get an instant answer.

```
