## Design System

| Property | Value |
|----------|-------|
| Tool | none. shadcn gate is not applicable: the stack is locked to CSS Modules + CSS custom properties, with no component library (06-CONTEXT brief) |
| Preset | not applicable |
| Component library | none (hand-built React 19 components, CSS Modules) |
| Styling | CSS Modules per component + global CSS custom properties in `theme/tokens.css`, imported once in `app/layout.tsx`. `theme/tokens.ts` is the typed mirror (same names, raw values). Inline `style={}` is banned except for runtime geometry (sheet height, vehicle position) passed as CSS variables. |
| Icon library | none. Inline SVG glyphs drawn in-repo (`components/icons/Glyph.tsx`), on a 16px grid with a 1.5px ink stroke and `currentColor`. No emoji anywhere. |
| Map | leaflet 1.9.4 + react-leaflet 5.0.0 + @types/leaflet. Custom `L.divIcon` markers. `leaflet/dist/leaflet.css` is imported in the client map module. The map loads with `next/dynamic(..., { ssr: false })`. |
| Display font | **Archivo** (variable, `wght` + `wdth` axes), via `next/font/google`, `axes: ['wdth']`, `variable: '--font-display'` |
| Body font | **IBM Plex Sans**, weights 400/600, via `next/font/google`, `variable: '--font-body'` |
| Figure font (optional mono) | **IBM Plex Mono**, weights 400/600, via `next/font/google`, `variable: '--font-mono'` |

### Why this font pairing (verified, not assumed)

- **Archivo** is a grotesque designed for high-density, data-heavy use, and its width axis (62–125) gives the condensed dispatch-board voice at heading sizes without a second family. Its default digits are proportional and it ships a `tnum` GSUB feature (verified), so every Archivo figure must set `font-variant-numeric: tabular-nums`.
- **IBM Plex Sans** is engineered and slightly mechanical, which suits operational copy. Its default digits are all the same width (verified: equal advance widths for 0–9), so table columns align even before `tnum` is applied.
- **IBM Plex Mono** is used only for the big readouts (ETA, distance), the tab counter figures, stepper timestamps and the demo clock. That is where the departure-board feel pays off. Mono digits are tabular by construction.
- None of these are banned (Inter, Roboto, Arial, Space Grotesk, system stack). All three are self-hosted by `next/font` at build time, so the browser makes no CDN request.
- **Global rule:** `html { font-variant-numeric: tabular-nums lining-nums; }` and every component that sets `font-family` re-declares `font-variant-numeric: tabular-nums`. No proportional figures anywhere.

```ts
// app/layout.tsx (contract, not final code)
const display = Archivo({ subsets: ["latin"], axes: ["wdth"], variable: "--font-display", display: "swap" });
const body    = IBM_Plex_Sans({ subsets: ["latin"], weight: ["400", "600"], variable: "--font-body", display: "swap" });
const mono    = IBM_Plex_Mono({ subsets: ["latin"], weight: ["400", "600"], variable: "--font-mono", display: "swap" });
// <html lang="en" className={`${display.variable} ${body.variable} ${mono.variable}`}>
```

## Typography

Exactly 4 sizes and 2 weights. Weights everywhere: **400 (regular)** and **600 (semibold)**. 500, 650, 700, 750 and 800 are banned. They caused the "indistinguishable 600/650/700 cluster" in 04-UI-REVIEW.

| Role | Family | Size | Weight | Line height | Extra |
|------|--------|------|--------|-------------|-------|
| Label | Archivo, `font-stretch: 100%` | 12px | 600 | 16px (1.33) | `text-transform: uppercase; letter-spacing: 0.06em`. Used for column headers, tab labels, status tags, stepper step names, section kickers |
| Caption | IBM Plex Sans | 12px | 400 | 16px (1.33) | Secondary lines in two-line rows, units, addresses, timestamps in text |
| Body | IBM Plex Sans | 14px | 400 / 600 | 20px (1.43) | All body text, table cells, buttons, chat, inputs. 600 is for row primary text (medicine name, hospital name) and button labels |
| Heading | Archivo, `font-stretch: 75%` | 20px | 600 | 24px (1.2) | Top-bar title, sheet titles, panel section titles, counter figures in mono (see below) |
| Display | IBM Plex Mono | 40px | 600 | 44px (1.1) | Tracking ETA readout, delivered-at readout. Nothing else |

Sizes in use: **12, 14, 20, 40**. Caption and Label share the 12px size and differ only in family and case.

- Counter-board figures (tab counts) use IBM Plex Mono 20px/24px, weight 600.
- Stepper timestamps and the demo clock use IBM Plex Mono 12px/16px, weight 400.
- The body line height is 20/14 = 1.43. This is a deliberate deviation from 1.5 for dispatch-board density and keeps every line box on the 4px grid. Chat answers use the same value.
- **Exception:** text inputs (chat prompt, sign-in select) render at **16px** on `(max-width: 767px)` only, so iOS Safari does not zoom on focus. No other element uses 16px.
- Max measure: 64ch for any paragraph (chat answers, empty-state bodies).
- Figures: tabular everywhere (see Design System). Use the real minus sign `−` (U+2212) for negative factors, `×` (U+00D7) for clock multipliers and `→` (U+2192) for from → to. These are text characters, not icons.

**Accent is reserved for exactly these elements:**
1. Primary CTA fills: "Accept transfer", "Accept all (N)", "Sign in", "Send" (chat).
2. Focus-visible ring (2px solid, 2px offset) on every focusable element except accent-filled buttons, which take an ink ring.
3. Active counter-board tab indicator (3px bar at the cell bottom).
4. Selected-hospital emphasis: the 3px accent ring around the selected marker and the 3px left rule on the selected table/list row.
5. The remaining-route polyline and the "In transit" status tag in tracking (06-03).
6. The current step dot in the order status stepper (06-03).
7. Inline text links ("Demo sign-in", "Retry live").

Accent is **never** used for: Refresh, the role switcher, the Map/List toggle, section headings, risk levels, chart bars, or decorative fills. Those are ink or ink-outline.

No gradients of any kind, no glow, no blur/backdrop-filter, no translucency on surfaces (all floating surfaces are opaque `--color-surface`). The advisory hatch is an SVG `<pattern>`, not a CSS gradient.

### Risk scale (semantic, colour-blind safe, never colour-only)

Data mapping: `Severity` from `lib/contracts.ts` is `"critical" | "warning" | "ok"`. The UI label for `warning` is **"Low"**. Hospital-level risk (marker, list row) = the **worst** `InventoryEntry.severity` across that hospital's medicines.

| Level | Data key | Label (exact text) | Glyph (shape) | Fill / stroke | Text colour on tint | Tint bg | Contrast |
|-------|----------|--------------------|---------------|---------------|---------------------|---------|----------|
| Critical | `critical` | `Critical` | **Filled diamond** (square rotated 45°) with a surface `!` | fill `#B42318`, 2px ink stroke | `#B42318` | `#FBE5E0` | text on tint **5.44:1**; text on surface 6.25:1; white `!` on fill 6.57:1 |
| Low | `warning` | `Low` | **Filled triangle**, point up, with an ink `!` | fill `#D99A1E`, 2px ink stroke | `#7A5100` | `#FAEFD4` | text on tint **6.11:1**; text on surface 6.64:1; ink `!` on fill 7.05:1 |
| OK | `ok` | `OK` | **Hollow circle**, 3px ring, no inner mark | ring `#5C6657`, fill surface | `#5C6657` | `#EAE7DF` | text on tint **4.86:1**; text on surface 5.71:1; ring on map tile ≈4.65:1 |

- Three cues on every risk display: **shape + label text + colour**. Fill vs. hollow also separates Critical from OK for deuteranopes/protanopes, whose Critical and OK hues land at similar luminance.
- Non-text contrast: every marker shape has a 2px ink (`#1C1B18`) stroke over a 3px surface halo. The ink stroke is ≥13:1 against the filtered tiles, so markers clear 3:1 on any tile. This matters because the Low fill alone is only 1.9:1 against tiles.
- Status tags (tables, sheets): `[glyph 12px] LABEL` using the Label type role, tint background, 2px radius, 4px horizontal padding.
- Sort order is always Critical → Low → OK, then by days of cover ascending.

## Motion

Only these motions exist. Everything else is instant.

| Motion | Duration | Easing | `prefers-reduced-motion: reduce` fallback |
|--------|----------|--------|-------------------------------------------|
| Sheet enter (right sheet slide-in, bottom-sheet snap) | 240ms | `cubic-bezier(0.2, 0, 0, 1)` | Instant (0ms), no slide |
| Sheet exit | 160ms | `cubic-bezier(0.4, 0, 1, 1)` | Instant |
| Outbreak marker pulse (ring scales 1.0 → 1.8, opacity 0.6 → 0) | 2000ms, infinite | `ease-out` | No animation. A static 2px **dashed** critical ring at 1.5× radius (still shape-encoded) |
| Selected marker emphasis (scale 1.0 → 1.25) | 120ms | `ease-out` | Instant |
| Counter-board active indicator move | 120ms | `ease-out` | Instant |
| Map pan/zoom to a selection (`flyToBounds`/`panTo`) | 400ms | Leaflet default | `animate: false` |
| Vehicle movement along the route (06-03) | Continuous, `requestAnimationFrame`, position from the demo clock | linear along path | Position updates in discrete steps at **1 Hz** with no tweening. The information stays and the smooth motion is removed |

- Skeletons are **static** blocks with no shimmer.
- Read `prefers-reduced-motion` in CSS (`@media`) for CSS animations, and through `window.matchMedia` for Leaflet `animate` options and the vehicle loop.
- Tokens: `--motion-fast: 120ms; --motion-sheet-in: 240ms; --motion-sheet-out: 160ms; --motion-pulse: 2000ms; --ease-out: cubic-bezier(0.2, 0, 0, 1); --ease-in: cubic-bezier(0.4, 0, 1, 1);`

### Map insets (keeps the attribution, zoom control and fitBounds clear of floating UI)

The app sets four CSS variables on the map wrapper from the current layout: `--map-inset-top`, `--map-inset-left`, `--map-inset-right`, `--map-inset-bottom`. These equal the space covered by the top bar, left panel, right sheet and bottom sheet (plus 16px). Then:

```css
.leaflet-top    { top:    var(--map-inset-top); }
.leaflet-left   { left:   var(--map-inset-left); }
.leaflet-right  { right:  var(--map-inset-right); }
.leaflet-bottom { bottom: var(--map-inset-bottom); }
```

- Attribution control: Leaflet's default `bottomright`, **never removed, never covered**. The text is `&copy; <a href="https://www.openstreetmap.org/copyright">OpenStreetMap</a> contributors`, after Leaflet's default prefix. On XS its bottom offset tracks the bottom sheet height, so it sits above the sheet at peek and half. At the full snap no map pixels are visible.
- Zoom control: `topright` (below the top bar via the inset). It is hidden on XS, where pinch zoom covers it.
- `fitBounds(bounds, { paddingTopLeft: [insetLeft + 24, insetTop + 24], paddingBottomRight: [insetRight + 24, insetBottom + 24] })`. Refit when a sheet opens or closes. `minZoom: 11`, `maxZoom: 18`.
- Chat FAB position: `right: calc(var(--map-inset-right) + 0px); bottom: calc(var(--map-inset-bottom) + 40px);`. The extra 40px keeps it above the attribution line.

### Network panel (the 6 data sections) — `data-testid="dashboard-grid"`

## Map Contract (06-02)

- **Data join:** `/api/hospital-locations` (positions) joined with `/api/results` (`hospitals[]`, `inventory[]`) by `id`. Hospitals present in results but without a position are omitted from the map and counted in the legend footnote. Positions are always `[lat, lng]`.
- **Marker element:** `L.divIcon({ className: styles.marker, html, iconSize: [44, 44], iconAnchor: [22, 22] })`. The 44×44 box is the hit area, and the glyph is drawn centred as inline SVG:
  - Critical: diamond with a 24px diagonal, red fill, surface `!`.
  - Low: triangle 24px wide × 21px tall, ochre fill, ink `!`.
  - OK: circle 18px, 3px ok-grey ring, surface fill.
  - All shapes: a 6px surface halo stroke drawn first, then a 2px ink stroke.
- **Name tag:** always shown, centred below the glyph. Body 12px is not used; it uses the Caption role at weight 600 (12/16), ink text on surface, 1px ink-3 border, 2px radius, padding `2px 4px`. Clicking the tag selects the hospital (it is part of the icon element).
- **Outbreak:** an extra critical-red ring behind the glyph, pulsing (see Motion), plus `OUTBREAK` appended to the name tag text.
- **Selected:** glyph scale 1.25, a 3px accent ring (r = 20px) with a 2px surface gap, the name tag in ink bg + surface text, and `zIndexOffset: 1000`.
- **Keyboard / AT:** Leaflet 1.9.4 already sets `tabindex="0"` + `role="button"` on marker icons (`keyboard: true`, the default) and maps Enter to click. The implementation must add:
  - `aria-label` = `{Hospital}, {risk label}: {worst medicine} {cover} days cover` (example: `Northgate General, critical: Paracetamol 10 days cover`). Append `, outbreak` when flagged and `, selected` when selected.
  - `aria-pressed` = selected.
  - A `keydown` handler so Space also selects.
  - Updates to these attributes on every data or selection change (via `eventHandlers.add` + an effect).
  - Markers are added in order Critical → Low → OK, then by name, so Tab reaches the worst first.
- The map wrapper is `<section aria-label="Hospital map">`. A visually-hidden paragraph inside it says `{n} hospitals on the map. Use Tab to move between hospitals, or switch to List.`
- **Transfers overlay (06-02, Moves tab active):** straight connectors from sender to receiver, 2px ink-3 dashed `4 6`, plus a small arrowhead glyph at 60% of the line. Legend label: `Planned transfer (straight line, not a road)`. No road routes are fetched in 06-02.
- **Click on empty map:** does nothing. It never clears the selection, because accidental clears are costly.

## Accessibility Contract

- **Focus-visible:** `:focus-visible { outline: 2px solid var(--color-accent); outline-offset: 2px; }`. On accent or critical fills the outline is `var(--color-ink)`. On markers the outline is drawn as a ring around the 44px hit box. `outline: none` without a replacement is banned.
- **Skip link** (first focusable): `Skip to results`. It moves focus to the counter-board tablist.
- **Keyboard paths:** Tab order is top bar → panel tabs → active section rows → map markers (worst first) → legend → chat FAB. Escape closes the topmost sheet or menu and returns focus to the invoker. Opening a sheet moves focus to its heading (`tabindex="-1"`). Sheets are non-modal regions (`role="region"`, `aria-labelledby`). The mobile full-screen chat is modal (`role="dialog"`, `aria-modal="true"`, focus trapped).
- **Screen reader:** markers as specified in the Map Contract. Sparklines and forecast strips are `aria-hidden="true"` with an adjacent visually-hidden sentence, for example `7-day usage, oldest first: 31, 30, 33, 29, 35, 34, 32.` and `30-day forecast, mean 39.9 tablets a day. Days 15 to 30 are advisory.` The ETA element is not live. Status changes are announced through one polite live region (`role="status"`).
- **Contrast:** all text pairs are ≥4.5:1 (table above). Non-text UI and marker strokes are ≥3:1. The two failures in 04-UI-REVIEW (`#94a3b8`, advisory band) are gone by construction: ink-3 is the lightest text colour.
- **Targets:** ≥44×44px on `(pointer: coarse)`, ≥32px tall otherwise (≥24px WCAG 2.2 minimum). Marker hit boxes are always 44px.
- **Never colour-only:** risk, status, advisory, outbreak, simulated, snapshot and selection all carry text or shape.
- **Zoom:** usable at 200% browser zoom on 1280px. The panel and sheets scroll internally, and the top bar wraps the role switcher into the menu below 768 CSS px.
