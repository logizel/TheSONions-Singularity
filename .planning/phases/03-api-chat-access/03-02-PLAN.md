<objective>
Serve precomputed ResultsJSON over API and enforce hospital scoping + moves/orders role gate.

Purpose: The dashboard and chat clients need the same numbers the engine produced. This plan creates the GET /api/results endpoint that serves the precomputed blob verbatim, and extends middleware with hospital-level scoping so hospital admins can only write their own hospital's data while network admins have full access including moves and orders.

Output: Working app/api/results/route.ts serving ResultsJSON, and middleware.ts with hospital scoping + moves/orders role gate.
